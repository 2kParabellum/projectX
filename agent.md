# Agent

Инструкция агенту, как работать с md-файлами этого проекта.

## Файлы

- 'architecture.md' - актуальная архитектура проекта и правила зависимостей между модулями.
- `idea.md` — описана общая идея проекта
- `current_state.md` — здесь описано то, над чем непосредственно работаем сейчас
- `agent.md` — эта инструкция.

## Правила

- Перед началом работы обновляй current_state.md: туда пишешь то, что собраемся сделать. Если изменение маленькое или идет в рамках другого плана - то это небольшая правка, если же мы переходим какому-то новому по смысле куску - то мы полностью его обновляем. Цель файла - если закончатся токены в середине большой разработки - чтобы другая нейронка могла подхватить весь прогресс
- `agent.md` трогать нельзя. Этот файл меняет только пользователь.
- То зачем все делаем - описано в idea.md
- Перед правкой механик сначала сверяйся с текущими md-файлами, потом меняй код, потом синхронизируй документы.
