## Как устроен сбор

Не повторяем старый обход всех событий через `/events/keyset`.

- `GET /sports` — каталог лиг. Киберспорт — строки с тегом `64` в `tags`.
- На каждую уникальную `series` — `GET /events?series_id=...&active=true&closed=false&end_date_min=...`.
- `end_date_min` нужен, потому что Gamma оставляет сыгранные матчи `closed=false`.
  Окно — `end_date_slack_hours` (12) назад от сейчас.
- Приоритетные лиги из `config/sources.yaml` идут первыми.
- В файл пишется сырой JSON: `payload.catalog` и `payload.events`, поля не выкидываются.
- `parse()` по-прежнему заглушка.

## Что не трогали

- Стакан CLOB. В сырых рынках уже есть `bestBid` / `bestAsk` / `outcomePrices`.
- `load_settings()` — всё ещё `NotImplementedError`. Сбор читает только блок
  `polymarket` из `config/sources.yaml`.
- Букмекеры, сопоставление, детектор, телеграм.

## Решения, которые уже приняты

- Внутри системы цена — только десятичный коэффициент (`Decimal`). В сыром
  снимке цены лежат как у Gamma, перевод будет на границе парсера.
- Все наши времена — timezone-aware UTC. Имя файла снимка тоже в UTC.
- Неполный набор исходов не считается. Нераспознанный рынок пропускается.
- Ставки не делаются. `fetching_old` не импортируется.
